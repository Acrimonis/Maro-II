Agree with the question currently open — the answer a confirmation gate is waiting for.

  [no param]       Agree. If the proposal has moved since the question was asked, re-ask rather
                   than assume the agreement still applies: a gate names its action, and a gate
                   that has moved is re-asked.

  impl             Agree and run the full `#implement` pipeline — Code → implement + build → Ask
                   review → Architect report.

than guessing a target. The agreement covers the action the open question named and nothing else.
