## #list

Dashboard of every tracked feature. Alias: `#features`.

  [no param]  Print a compact dashboard of all features from the ## Feature Summaries
              blocks in GLOBAL_CONTEXT.md, in the shape docs/xtrack-templates.md holds —
              each feature's name, status, created and modified with its summary bullets,
              sorted by modified descending (most recently touched first).

  Read-only: no state is written, and no focus change occurs.
