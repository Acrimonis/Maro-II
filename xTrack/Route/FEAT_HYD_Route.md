## State

**A saved route keeps its ends and is found by them.** The two flagged markers a route ran between now persist with the track it became and with that track's summary — `routeStartMarkerId` and `routeDestinationMarkerId` at proto 20/21, an empty string meaning *that end was not a marker* — and the index pass projects both beside the `route` flag, so the acquisition's match reads them without loading a track. Only a flagged-marker end carries an identity; a current-position or standing-marker end leaves the strings empty, and no index version was bumped, an absent string decoding to the honest *no marker recorded*, which is why routes saved before the change never match.

**Arming on that pair answers with the stored line, not a search.** When both resolved ends are markers and a stored route's pair equals them, `armRouteMode` loads the track, rebuilds the plan through the shipped `routePlanOf`, and arms with it: no `routesToCompute`, no `startLookup`. The plan instance is registered in the session under the matched track id, so `isRouteSaved` reads true and the save door greys by itself; `Choosing.start` is the line's own first point, and the match skips the short-pair guard the search alone keeps — the fallback to a search, where the matched file will not load, re-applies that guard and stands the mode back down with the shipped toast.

**The return trip is the same line mirrored.** `storedRouteMatch` runs a second pass for the reversed pair and answers it flagged; `mirroredPlanOf(track, nowMs)` is the forward inverse with its lists reversed — `routePlanOf`'s points and leg times reversed, so mirrored leg *k* is stored leg *n−1−k* and the stored milliseconds carry over with no pace arithmetic redone. A mirrored line is a new plan: it takes the arming instant for its name and registers no session link, so its save door stays open. It can only arm when **each** marker carries both `routeOrigin` and `routeDestination`, the drawer offering a marker at an end only while that end's flag stands — the feature's limiting fact, recorded in R84 and R86.
