# Feature: Markers

**Description:**
User-defined markers on the map — Pin, Circle, and Corridor geometries. Sea-distance-gated proximity matching (land-blocking with 10° sampling + 10m grazing tolerance). On-demand "where am I?" query via boat marker tap. Animated drawer UI (portrait=bottom, landscape=left) for creation, editing, and match results. Management page with swipe-to-delete (track list paradigm).
